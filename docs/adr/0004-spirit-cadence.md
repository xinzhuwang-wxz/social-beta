# ADR-0004 · 池塘精灵按状态分段：两头主动，中间沉默

- 状态：已接受（推翻了「默认 SILENT 是主路径」的原设计）
- 日期：2026-08-12
- 影响面：`InterventionPolicy`、issue #8 的验收标准、测试的正负例配比

## 背景

原设计是「精灵默认沉默，只在五个协作断点介入，测试里负例数量必须多于正例」。
依据是 CHI 2026 关于群聊中 agent 何时该发言的研究：只在出现协作断点时介入，
其余时刻的介入都是骚扰。

## 推翻的理由

那条研究结论针对的是**已经在正常运转的群聊**。而我们的池塘有一个它没覆盖的阶段：
**刚组队的一群陌生人**。

在这个阶段，「没有人说话」不是「大家在正常协作所以不需要打扰」，
而恰恰是**破冰失败**——这正是本产品要解决的核心痛点：

> 最远的距离不是宿舍到早八教室，而是你们都对一件事感兴趣、都想组队，
> 但没有一个人先问一句「要不要一起」。

一个刚把五个陌生人凑到一起、然后自己闭嘴的精灵，是失职，不是克制。

## 决策

**介入节奏按池塘状态分段，不是全程统一。**

| 池塘状态 | 精灵行为 | 具体动作 |
|---|---|---|
| `forming` 刚组队 | **主动** | 破冰话题卡、角色清单卡、关键项决策卡 |
| `active` 事情定了 | **沉默为主** | 仅在 stall / undecided / newcomer 断点介入 |
| `done` 事件结束 | **主动一次** | 回流卡：索要返图、提议生成共同海报 |
| `dormant` 休眠 | **主动一次** | 唤醒卡：把上次的约定端出来 |

两头主动、中间沉默。精灵的目标在 `forming` 阶段是明确的：
**让这支小队尽快破冰，尽快把该定的定下来。**

## 后果

- `InterventionPolicy` 的入参必须包含池塘状态，不能只看转录内容。
- 测试的正负例配比要求随之修正：`active` 阶段仍要求负例（沉默）显著多于正例；
  但 `forming` 阶段要求的是**主动率**，沉默反而是缺陷。
- issue #8 的验收标准需要同步修订（「SILENT 是主路径」不再全局成立）。
- 仍然保留的约束：介入形式是**发卡**而非说话。卡片结构化、可点击、
  点击直接写回 `episode`，不需要二次 LLM 解析，也不抢占用户之间的互动空间。

## 边界

`forming` 阶段的主动**不等于话痨**。仍然限量：
一次破冰话题卡 + 一次角色清单卡 + 每个未收敛项一张决策卡。
发完就等，不追问、不催促 —— 主动是把选择摆出来，不是逼人回答。
