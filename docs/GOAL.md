## 终局（Done 的唯一定义）

**不是 13 个 issue 被关掉。** Done 是下面五条同时为真：

1. **一个真实的大学生，在手机浏览器上，不填任何资料**，能走完完整闭环：
   注册 → 发一句意图 → 收到 3–5 张带真实理由的候选卡 → 亲手接管 → 开出池塘 →
   在群里协作把事定下来 → 事后传返图 → 拿到共同海报与一句「下次的理由」→
   被那句话唤醒 → 再次成行。**中途没有任何一步是假的、占位的、或「以后再做」的。**

2. **他的画像是长出来的，不是填出来的。** 三次活动后，「我的切面」页面上的内容
   他自己看了会认（每条都能溯源到具体池塘），且他能逐条改、逐条删、逐切面设可见度。

3. **1000 人模拟跑通，冷启动拐点曲线可导出。** 模拟驱动的是同一条 `PoolEngine` 缝，
   不是旁路写库。随机抽 20 人的蒸馏画像通过「像个人」的人工检查。

4. **四条红线在测试里恒为真**（违反即回滚，不是待办）：
   `ai_sent_message === 0` · 无绕过接管创建 pool 的路径 ·
   `private` 切面泄漏计数为 0（RLS 层保证，不是 prompt 约束）· 记忆可见可编辑可删。

5. **L2 全删重建等价性回归通过。** 删光 facet / relation / 知识图谱后从 L1 重建，
   结果等价 —— 这是「Postgres 是唯一真相源」这条架构承诺唯一能被证伪的地方。

3. **偏离必须当场收敛。** 发现实现与 PRD 不一致时，二选一：改代码，或改 PRD 并说明理由。
   **不允许留着不管，也不允许口头记下继续往前跑。**

## 不可协商的约束

- **不用 stub / mock / 假数据。** 唯一例外是 #12 的 1000 虚拟学生 —— 那是产品能力的证明工具，
  且必须驱动同一条缝。除此之外：没有假页面、没有硬编码的候选、没有模板化的「AI 生成理由」。
- **不推后、不绕开问题。** 遇到难点就地解决。如果某个决定确实需要人拍板，停下来问，
  不要选一个更容易的实现然后标记 TODO。
- **测试跑在真实 Postgres 上**；模型侧用录制回放（cassette，首次录真实豆包响应），不手写假响应。
- **隐私边界落在 RLS**，不落在 prompt。prompt 里的约束是建议，数据库里的才是保证。
- **Agent 默认沉默是主路径**，不是边缘情况 —— 测试里负例数量应显著多于正例。

## 最终验收：UI-only autoresearch

全部里程碑过完后，跑一轮 `/autoresearch`，**以真实用户身份实际操作产品**。

### 硬约束：UI-only

参与验收的 agent **只能通过浏览器操作产品**。明确禁止：

- 读源码 · 查数据库 · 看服务端日志 · 调内部 API · 看测试用例

它们只能看到真实用户能看到的东西。发现问题时，记录的是**用户视角的症状**
（「我点了接管，但什么都没发生，也没告诉我为什么」），不是代码诊断。
症状收齐之后，再回到代码里定位归因。

### 至少覆盖这些人格，各自独立跑完整旅程

| 人格 | 要暴露什么 |
|---|---|
| 大一新生，零历史，零社交数据 | T0 冷启动是否真的可用，还是空推荐位 |
| 社恐，想去但不敢先开口 | 提案卡与草稿是否真的降低了开口压力 |
| 活跃组局者，一周发三条意图 | `saturation` 上限是否生效，会不会被榨干 |
| 从不回消息的人 | `responsiveness` 是否把他降权，别人是否被反复浪费 |
| 跨专业找队友，需求很具体 | 硬约束抽取是否准确，互补性是否真的起作用 |
| 考试周的人，突然沉寂两周 | 时间衰减与休眠唤醒是否符合直觉 |
| 只想找一次性搭子，不想深交 | 系统会不会强行推进关系，边界感如何 |
| 想找长期社团 | crew 孵化路径是否走得通，是否需要真人确认 |
| 隐私敏感者，把多数切面设为私密 | 可披露视图是否真的收窄，会不会仍被看穿 |
| 想让 AI 替他聊天的人 | 产品是否明确拒绝，且拒绝得体不说教 |

### 验收结论必须回答的三个问题

1. **拿掉 AI 之后，产品还成立吗？** 如果成立，说明 AI 没做不可替代的事 —— 这是失败信号。
2. **有多少连接被真人接管，并真的发生了共同行动？** 不看 AI 对话轮次，只看接管率与成行率。
3. **有没有留下下一次互动的理由？** 复现率是最终答案。

### 反指标同样要出数

Agent 发言占比（越低越好）· AI 代答次数（**必须恒为 0**，非零即整轮验收不通过）。
